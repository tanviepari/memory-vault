# Memory Vault

> Where feelings glow.

An Inside Out inspired memory journal for mobile. Each moment becomes a glowing emotional orb on a shelf, colour-coded by feeling (Joy, Sadness, Anger, Fear, Disgust), with a photo and a diary entry attached. Your most important moments live on five Core Memory pedestals.

Built with Flutter and Firebase.

## Features

- **Memory orbs:** glowing, softly floating orbs with the photo as an overlay, coloured by emotion
- **Swipeable racks:** 4 shelves × 6 orbs per rack. A new rack appears only when the last one is full, and the app always opens on your latest rack
- **Notes-style editor:** photo on top, emotion picker below, then title and diary. Pick the date, edit anytime
- **Core memories:** pin up to 5 special memories on glowing pedestals
- **Filter by month and year** to revisit any period
- **Memory popup card** with blurred backdrop, pin, edit and delete
- **Accounts:** splash screen, username and password sign up and login, profile page with name, photo, stats, emotional mix and sign out
- **Cloud sync:** each user's memories and photos are stored privately in Firestore

## Tech stack

| Area | Tools |
|---|---|
| App | Flutter, Dart |
| Auth | Firebase Authentication (username mapped to an email behind the scenes) |
| Database | Cloud Firestore |
| Images | `image_picker`, compressed and stored as base64 in Firestore |
| CI | GitHub Actions builds the release APK |

## Data structure

```
users/{uid}                    profile: name, username, avatar, joined
users/{uid}/memories/{id}      title, text, emo, image, core, date
```

Firestore rules restrict each user to their own data:

```
match /users/{uid}/{document=**} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}
```

## Run it locally

Requires Flutter (stable) and a Firebase project with Email/Password auth and Firestore enabled.

```bash
git clone https://github.com/tanviepari/memory-vault.git
cd memory-vault
flutter pub get
flutterfire configure   # connect your own Firebase project
flutter run
```

## Get the APK

Go to the **Actions** tab, open the latest **Build APK** run and download the `memory-vault-apk` artifact. Extract it and install `app-release.apk` on an Android phone.
